# Логіка роботи

1. Користувач вводить свої дані (освіта, досвід, навички).
2. Система перевіряє вакансії у базі.
3. Відбирає ті, які відповідають умовам:
    - Освіта не нижча за вимоги.
    - Досвід ≥ мінімального значення.
    - Навички мають збіг 50% або більше.
4. Формується список рекомендацій.
