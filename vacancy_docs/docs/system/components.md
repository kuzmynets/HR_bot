# Компоненти системи

## 1. База знань
Містить опис вакансій, їх вимоги, необхідні навички, досвід і освіту.

## 2. Інтерфейс користувача
Користувач взаємодіє із системою через Telegram-бота, який ставить запитання і формує підбір вакансій.

## 3. Механізм логічного висновку
Аналізує відповіді користувача і відбирає вакансії за відповідністю вимогам.

## 4. База правил
Містить логіку підбору — умови для освіти, досвіду та навичок.
